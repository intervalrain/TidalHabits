# TidalHabits 功能概述

## 應用程式簡介

TidalHabits 是一款專注於自律習慣養成的 iOS App,透過番茄鐘機制與獎勵系統,幫助使用者建立並維持良好習慣。

## 核心概念

### 1. 習慣 (Habit)
- **定義**: 使用者自定義的日常活動項目
- **屬性**: 名稱、圖示、預設時長、獎勵星星數
- **用途**: 作為「常用項目」,可快速加入行事曆或立即開始
- **範例**: 運動、寫論文、看書、冥想

### 2. 番茄鐘 (Pomodoro/Check-In)
- **定義**: 執行習慣時的專注時段
- **特性**:
  - 開始後手機螢幕鎖定
  - 計時到達時提醒
  - 可提前終止 (會提示損失星星數)
  - 可延長時間 (依設定可獲得延長獎勵)

### 3. 獎勵系統 (Reward)
- **星星 (Stars)**: 完成習慣獲得的虛擬貨幣
- **獎勵項目**: 使用者自定義的兌換項目 (如吃大餐、看電影)
- **兌換機制**: 使用累積的星星兌換獎勵

### 4. 統計 (Statistics)
- 追蹤習慣執行歷史
- 視覺化圖表呈現數據
- 分析完成率與連續記錄

## Tab Bar 架構

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│   首頁    │  行事曆   │   習慣   │   統計   │   設定   │
│  (Home)  │(Calendar)│ (Habit)  │(Stats)   │(Settings)│
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 1. 首頁 (Home)
- **功能**:
  - 顯示今日待完成習慣
  - 快速開始番茄鐘
  - 顯示今日進度與獲得星星數
  - 即將到期的提醒

### 2. 行事曆 (Calendar)
- **功能**:
  - 檢視已安排的習慣
  - 查詢過去執行記錄
  - GitHub 風格的熱度圖 (Heatmap)
  - 月曆/週曆檢視

### 3. 習慣 (Habit)
- **功能**:
  - 建立/編輯/刪除習慣
  - 習慣列表檢視
  - 快速啟動番茄鐘
  - 設定習慣提醒

### 4. 統計 (Statistics)
- **功能**:
  - 各習慣統計資訊
  - 每日執行時長圖表
  - 完成次數統計
  - 最長連續記錄
  - 完成率分析
  - 累積星星數

### 5. 設定 (Settings)
- **功能**:
  - 番茄鐘行為設定
  - 延長時間設定
  - 延長獎勵設定
  - 語言設定
  - 通知設定
  - 主題設定 (如有)

## 功能模組 (Features)

### Feature 模組對應

| Tab Bar | Feature 模組 | 說明 |
|---------|-------------|------|
| 首頁 | `Home` | 今日總覽與快速操作 |
| 行事曆 | `Calendar` | 行事曆檢視與記錄查詢 |
| 習慣 | `Habit` | 習慣管理 (CRUD) |
| 統計 | `Statistic` | 統計分析與圖表 |
| 設定 | `Settings` | 應用程式設定 |
| - | `CheckIn` | 番茄鐘核心功能 |
| - | `Reward` | 獎勵系統 |
| - | `User` | 使用者資料管理 |

## 使用者流程

### 主要使用情境

#### 情境 1: 新使用者建立第一個習慣
```
1. 開啟 App → 首頁
2. 前往「習慣」Tab
3. 點擊「新增習慣」
4. 輸入習慣資訊:
   - 名稱: "運動"
   - 圖示: 選擇運動圖示
   - 預設時長: 60 分鐘
   - 獎勵星星: 30 stars
5. 儲存習慣
6. 返回首頁,點擊「開始」啟動番茄鐘
```

#### 情境 2: 執行番茄鐘
```
1. 選擇習慣「運動」
2. 點擊「開始」
3. 系統進入番茄鐘模式:
   - 螢幕鎖定
   - 顯示倒數計時
   - 背景持續計時
4. 時間到達:
   Option A: 點擊「完成」→ 獲得 30 stars
   Option B: 點擊「延長 30 分鐘」→ 繼續計時
   Option C: 提前終止 → 提示損失星星,確認後結束
5. 記錄儲存至統計
```

#### 情境 3: 兌換獎勵
```
1. 累積星星達 100
2. 前往「設定」→「獎勵管理」
3. 檢視可兌換項目
4. 選擇「看電影」(50 stars)
5. 確認兌換
6. 星星數扣除,獎勵標記為已兌換
```

#### 情境 4: 查看統計
```
1. 前往「統計」Tab
2. 選擇習慣「運動」
3. 檢視:
   - 本週執行時長圖表
   - 完成次數: 本週 5 次
   - 最長連續: 12 天
   - 完成率: 87%
   - 累積星星: 450 stars
```

## 設計原則

### 使用者體驗
- **簡潔**: 介面清爽,減少認知負擔
- **直覺**: 操作流程自然,無需學習
- **專注**: 番茄鐘期間最小化干擾
- **激勵**: 透過視覺化數據與獎勵激勵使用者

### 技術原則
- **離線優先**: 所有功能離線可用
- **效能**: 流暢的動畫與即時回饋
- **可靠**: 確保資料不遺失
- **可測試**: 所有功能有對應測試
